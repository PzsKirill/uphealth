# Карта сайта — структурный референс по refeel.ru

> Источник: https://refeel.ru/ — взято как структурный референс для проекта UpHealth Shopify.
> Тексты, бренд-копирайт и креативы НЕ переносим — только архитектура разделов, URL-схема, иерархия.

---

## 1. Верхнеуровневая структура

```
/
├── Главная
├── Каталог (/shop)
│   ├── Фильтр по формату:   Стики · Мармелад · Напитки · Протеин · Наборы · Акции · Новое
│   └── Фильтр по состоянию: Энергия · Сон · Релакс · Бьюти · Сила
├── Товары (по slug)
├── Велнес-тест           (внешний сервис → typeform / refeel-care.ru)
├── О нас                 (/aboutus)
├── Опт / B2B             (/business)
├── Доставка / Контакты   (/delivery)
├── Бонусы / Лояльность   (/bonuses)
├── FAQ / Вопросы         (/faq)
├── Аккаунт
│   ├── Вход              (/members/login)
│   └── Регистрация       (/members/signup)
└── Документы (оферта, политика обработки данных)
```

## 4. Каталог `/shop`

URL-схема фильтров (refeel использует параметры платформы):
```
/shop                              — все товары
/shop?...storepartuid=СТИКИ        — фильтр по формату
/shop?...storepartuid=Энергия      — фильтр по состоянию
```

**На Shopify это укладывается в:**
- 1 общую коллекцию `all-products`
- 7 коллекций по формату: `sticks`, `gummies`, `drinks`, `protein`, `sets`, `sale`, `new`
- 5 коллекций по состоянию (через теги): `state-energy`, `state-sleep`, `state-relax`, `state-beauty`, `state-strength`
- Фильтры сайдбара: формат · состояние · цена (range) · бренд (опц.)

**Структура страницы коллекции:**
- Breadcrumbs
- Заголовок коллекции + краткое описание (метаполе)
- Сортировка (популярные / новые / цена)
- Sidebar: фильтры (формат, состояние, цена)
- Grid: 4 кол. desktop / 3 tablet / 2 mobile
- Пагинация (или infinite scroll)

## 5. Страница товара

**Слева (Desktop):**
- Главная картинка + миниатюры (галерея, zoom on hover)

**Справа:**
- Название
- Цена (+ rrp / скидка, если есть)
- Вариант (вкус / объём)
- Кол-во порций
- Кнопка «В корзину» + опция рассрочки («Долями» / «Сплит»)
- Краткое описание
- Икон-список ключевых эффектов (4 пункта)
- Противопоказания (плашка)

**Табы / аккордеоны:**
- Что внутри
- Как принимать
- Состав
- Пищевая ценность (КБЖУ + % суточной нормы)

**Ниже:**
- Большой блок про технологию / ингредиент
- Отзывы
- Похожие товары
- Подарочные карты (cross-sell)

## 10. Маппинг refeel → Shopify

| refeel                     | Shopify                                                         |
|----------------------------|-----------------------------------------------------------------|
| `/shop` + параметр фильтра | Smart collection по тегу                                        |
| Параметр `storepartuid`    | Тег товара (`format:gummies`, `state:energy`)                   |
| Featured product в меню    | Mega-menu блок (theme section)                                  |
| Велнес-тест                | Внешняя ссылка или Shopify-app (например, Octane AI / Shop Quiz)|
| Бонусы                     | App: Smile.io / LoyaltyLion / Yotpo                             |
| Подарочные карты           | Native Shopify Gift Cards                                       |
| Рассрочка                  | App: Shop Pay Installments / локальные провайдеры (РФ)          |
